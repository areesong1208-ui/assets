# 잔여석 감시기 — RE : MOVE ERA (리무브 에라), 22일 공연

## ⭐ 최종 권장: `bookmarklet-final.js` (휴대폰/PC 공통)

ntok.go.kr은 달력 날짜 클릭이 delegated 핸들러라 스크립트 클릭이 먹지 않는다.
대신 사이트가 쓰는 좌석조회 API를 직접 호출해 판정한다(클릭·새로고침 불필요).

- 엔드포인트: `POST /ntok/pm/prfmng/selectSeatListInfo.do`
- 본문: `id=267191&timeId=82193`  (id=perfId, timeId=22일 19:30 회차)
- 응답: `{"result":"Y","seatList":[{"bookableCount":0,"className":"전석"}]}`
- 판정: `bookableCount > 0` 이면 잔여석 발생 → 소리·진동 + 예매하기로 스크롤
- 다른 공연/회차면 `PERF`(id)와 `TIME`(timeId)만 바꾸면 된다.
  timeId는 `inspect-net.js`로 날짜 클릭 시 요청을 캡처해 확인.

사용법: 이 코드를 북마크 URL에 넣고(맨 앞 `javascript:` 유지), 예매 페이지에서
주소창에 북마크 이름을 입력해 실행. 상단 초록 띠가 초 단위로 카운트다운되면 정상.

아래는 이전 버전들(참고용): 날짜 클릭 방식이라 이 사이트에선 새로고침이 안 됨.

---


한국예술종합학교 무용원 <RE : MOVE ERA> **22일 공연**의 잔여석만 감시합니다.
자동 클리커처럼 무작정 새로고침만 하는 게 아니라, **잔여석이 실제로 떴는지 스스로 판단**해서
`전석 0석`이 다른 숫자로 바뀌는 순간 **팝업 창**으로 알려줍니다.
(새로고침하면 날짜 선택이 풀리므로 **매번 22일을 자동으로 다시 선택**합니다.)

## 왜 이게 더 나은가
- 클리커는 좌석이 나왔는지 판단 못 해서 계속 화면을 지켜봐야 합니다.
- 이 스크립트는 페이지의 `예매가능 잔여좌석 → 전석 → 0석` 숫자를 직접 읽어서
  `0`이 아니게 되는 순간 자동으로 팝업을 띄웁니다. → 그때만 예매하면 됩니다.
- 실제 크롬 창을 띄우므로 봇 차단(403)에 잘 안 걸립니다.
- 새로고침 간격을 10~15초 랜덤으로 두어 서버가 비정상 트래픽으로 오해하지 않게 합니다.

## 설치 (PC 한 번만)
```bash
pip install playwright
python -m playwright install chromium
```
> 팝업(tkinter)은 파이썬 기본 내장이라 따로 설치할 필요 없습니다.

## 실행
```bash
python monitor.py
```
1. 크롬 창이 뜨면 스크립트가 **22일을 자동으로 선택**합니다.
   (자동 선택이 안 되면 창에서 직접 22일을 눌러주세요.)
2. 브라우저에 **22일의 `전석 0석`**이 보이는지 확인한 뒤, 터미널에서 **Enter** → 감시 시작.
3. 22일 잔여석이 뜨면 **맨 위에 팝업 경고창**이 뜹니다.
4. 팝업을 확인하고, 열려 있는 크롬 창에서 **직접 예매하기**를 누르세요.
   (예매까지 마친 뒤 터미널에서 Enter를 누르면 창이 닫힙니다.)

### 22일 자동 선택이 안 될 때
`monitor.py` 상단의 `DATE_SELECTOR`에 정확한 선택자를 넣으세요. 예:
```python
DATE_SELECTOR = "a:has-text('22')"        # 달력 링크가 <a>22</a> 형태일 때
# 또는
DATE_SELECTOR = "td[data-date='2026-08-22']"
```
크롬 창에서 22일 버튼을 **우클릭 → 검사(Inspect)**로 실제 태그를 확인하면 됩니다.

## 설정 바꾸기 (`monitor.py` 상단)
| 항목 | 설명 |
|------|------|
| `URL` | 감시할 공연 상세 페이지 주소 |
| `MIN_INTERVAL` / `MAX_INTERVAL` | 새로고침 간격(초). 기본 10~15초 |
| `AVAIL_ANCHORS` | 잔여석 숫자를 찾는 기준 문구 (`잔여좌석` 등) |

## 주의
- 예매 자체(결제·좌석선택)는 사람이 직접 합니다. 스크립트는 "알림"까지만 합니다.
- 간격을 1~2초로 너무 짧게 두면 오히려 일시 차단·캡차가 뜰 수 있으니 10초 이상을 권장합니다.
- 감시하는 동안 PC 화면이 꺼지지 않게 전원 옵션을 조정해 두세요.
