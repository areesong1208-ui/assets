# 국립극장 잔여석 감시기

자동 클리커처럼 무작정 새로고침만 하는 게 아니라, **잔여석이 실제로 떴는지 스스로 판단**해서
`전석 0석`이 다른 숫자로 바뀌는 순간 **팝업 창**으로 알려줍니다.

## 왜 이게 더 나은가
- 클리커는 좌석이 나왔는지 판단 못 해서 계속 화면을 지켜봐야 합니다.
- 이 스크립트는 페이지의 `예매가능 잔여좌석 → 전석 → 0석` 숫자를 직접 읽어서
  `0`이 아니게 되는 순간 자동으로 팝업을 띄웁니다. → 그때만 예매하면 됩니다.
- 실제 크롬 창을 띄우므로 봇 차단(403)에 잘 안 걸립니다.
- 새로고침 간격을 10~15초 랜덤으로 두어 서버가 비정상 트래픽으로 오해하지 않게 합니다.

## 설치 (PC 한 번만)
```bash
pip install playwright
python -m playwright install chromium
```
> 팝업(tkinter)은 파이썬 기본 내장이라 따로 설치할 필요 없습니다.

## 실행
```bash
python monitor.py
```
1. 크롬 창이 뜨면 예매할 **날짜(22일/23일 등)를 직접 선택**하세요.
2. 터미널로 돌아와 **Enter**를 누르면 감시 시작.
3. 잔여석이 뜨면 **맨 위에 팝업 경고창**이 뜹니다.
4. 팝업을 확인하고, 열려 있는 크롬 창에서 **직접 예매하기**를 누르세요.
   (예매까지 마친 뒤 터미널에서 Enter를 누르면 창이 닫힙니다.)

## 설정 바꾸기 (`monitor.py` 상단)
| 항목 | 설명 |
|------|------|
| `URL` | 감시할 공연 상세 페이지 주소 |
| `MIN_INTERVAL` / `MAX_INTERVAL` | 새로고침 간격(초). 기본 10~15초 |
| `AVAIL_ANCHORS` | 잔여석 숫자를 찾는 기준 문구 (`잔여좌석` 등) |

## 주의
- 예매 자체(결제·좌석선택)는 사람이 직접 합니다. 스크립트는 "알림"까지만 합니다.
- 간격을 1~2초로 너무 짧게 두면 오히려 일시 차단·캡차가 뜰 수 있으니 10초 이상을 권장합니다.
- 감시하는 동안 PC 화면이 꺼지지 않게 전원 옵션을 조정해 두세요.
