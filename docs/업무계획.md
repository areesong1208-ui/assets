# 삼성디스플레이 화질 용어 시멘틱 데이터 구축 — 업무 계획서

## 1. 목표 (Goal)

- **최종 목표**: 영어 → 한글로 번역된 IDMS 문서에 대한 **한글 답변(요약·질의응답)의 품질을 향상**시킨다.
- **핵심 수단**: 삼성디스플레이에서 사용하는 **화질(Picture Quality) 관련 용어**를 추출·정제하여, 번역/질의응답 시스템이 참조할 수 있는 **시멘틱 데이터(도메인 용어 지식베이스)**를 구축한다.
- **왜 필요한가**: 일반 기계번역/LLM은 디스플레이 도메인 전문 용어를 부정확하게 번역하거나(예: *mura* → "무라/얼룩/불균일" 혼용), 사내 표준 표기와 어긋나게 처리한다. 표준화된 용어 지식베이스를 근거(grounding)로 주입하면 번역·답변의 **일관성과 정확도**가 올라간다.

## 3. 추진 단계 (Phases)

### 1단계 — 용어 수집 (Term Collection)
- 출처: 삼성디스플레이 화질 관련 문서, IDMS 문서, 사내 표준 용어집, 공개 디스플레이 표준(IEC/VESA/SID 용어).
- 방법: 문서에서 화질 관련 명사구 추출 → 후보 용어 리스트업.
- **필요 입력**: IDMS 원문 문서(영/한). *(현재 미보유 — §6 확인 필요)*

### 2단계 — 시멘틱 데이터 스키마 설계 (Schema Design)
- 각 용어를 단순 대역쌍이 아니라 **의미 단위(개념)**로 정의: 영문 표준어, 한글 표준어, 동의어/변형표기, 범주, 정의, 번역 주의사항.
- 시멘틱 관계(상위/하위/관련 개념) 확장 여지 확보 → 후속 온톨로지/지식그래프화 가능.

### 3단계 — 시드 데이터 구축 (Seed Dataset)
- 핵심 화질 용어 50여 개를 범주별로 정리 → `data/display-quality-terms.csv`.
- 검증 가능한 근거(정의·주의사항) 포함.

### 4단계 — 검증 및 확장 (Validation & Expansion)
- 도메인 전문가/표준 대조로 표기·정의 검수.
- IDMS 실제 문서에서 신규 용어 반복 추출하여 확장.

### 5단계 — 번역/답변 품질 향상 적용 (Apply to Translation QA)
- 시멘틱 데이터를 **용어 사전(glossary) / 검색증강(RAG) 근거**로 주입.
- 번역·질의응답 프롬프트에 도메인 용어 제약 조건으로 결합.

### 6단계 — 평가 (Evaluation)
- 적용 전/후 한글 답변 품질 비교(용어 정확도, 표기 일관성, 사람 평가).

## 4. 시멘틱 데이터 스키마 (Schema)

`data/display-quality-terms.csv` 컬럼 정의:

| 컬럼 | 설명 |
|------|------|
| `id` | 용어 고유 ID (예: PQ-001) |
| `category` | 범주 (휘도/명암, 색, 계조, 결함·불량, 시간응답, 해상도·구조, 규격·측정) |
| `en_term` | 영문 표준 용어 |
| `ko_term` | 한글 표준 용어 (권장 표기) |
| `ko_synonyms` | 한글 동의어·변형표기 (`;`로 구분) — 번역 일관성 확보용 |
| `abbr` | 약어 (있는 경우) |
| `definition_ko` | 한글 정의 |
| `translation_note` | 번역 시 주의사항 / 흔한 오역 |

## 5. 일정 (개략)

- 1주차: 스키마 확정 + 시드 데이터(D2) 검토
